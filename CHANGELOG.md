## [1.1.0] - 2026-10-15

First complete release: tested, versioned and documented. Targets Azure Local 12.2609 (latest).
The ISO still has to be built and boot-verified on a Windows host with the ADK
(see `docs/getting-started/verify-build.md`); nothing in this release has booted yet.

### Features

- Arc readiness without Az modules: OAuth2 device-code sign-in plus Azure Resource Manager REST checks
  (resource provider registration, resource group, existing Arc machines, role sanity of the signed-in
  identity). Token and ids stay in memory; results carry a masked subscription id.
- Per-region endpoint lists (East US, West Europe, Australia East, Canada Central, India Central,
  Southeast Asia, Japan East, South Central US, US Gov Virginia) generated from the lists Microsoft Learn
  links to, with source URL and phase per entry, plus an optional Dell OEM list. `-Region` / `azureRegion`.
- Arc gateway mode (gateway FQDN probed, endpoints the gateway carries are skipped) and explicit proxy
  with bypass list for the HTTPS probes.
- Arc endpoints (`*.his.arc.azure.com`, `*.guestconfiguration.azure.com`, `*.dp.kubernetesconfiguration.azure.com`)
  must resolve to public IPs (Private Link Scopes are unsupported); HTTPS-inspection detection from the
  certificate chain (SslStream, works in WinPE).
- Active Directory: 464, 3268/3269, 445, 9389 added; UDP 88/389/464 where testable; RPC dynamic range
  documented as not scanned; NTP/W32Time reachability and clock-skew check as its own check.
- Environment Checker: failed checks itemised (name, status, severity, remediation, target); Connectivity
  validator receives region, proxy and Arc gateway; Network validator receives real inputs or is skipped
  with the reason; module resolved by explicit manifest path (version sub folder); runs in Windows PowerShell 5.1.
- Results: schema 1.1 (`docs/reference/results.schema.json`) with run id, node identity (serial, SMBIOS UUID,
  hostname), tool version and correct UTC timestamps; HTML report; `-Redact`; export to USB drive,
  SMB share or HTTPS (`-ExportTo`, menu option 8).
- Build: SHA256-verified PowerShell 7 download or `-PS7ZipSha256` for a supplied zip, ADK/WinPE add-on
  version check, `build-manifest.json` inside the image and next to the ISO, optional `-Brand`.
- Pinned, signature-checked Environment Checker module (`tools/modules/modules.lock.json`).
- Driver manifest with hashes and INF versions; `-DriverPath` documented for other OEMs.
- Pester 5 test suite, PSScriptAnalyzer settings, CI (analyzer, tests, link check, docs build),
  release-please, manual workflow that documents the ADK build.
- Docs: build verification procedure, walkthrough with sample output, sample results file.

### Bug Fixes

- Endpoint converter parsed markdown loosely and produced junk rows (`Management network`, `SSH`,
  `Kubernetes API server`, mangled encodings, stray backticks, port 8084). It is now strict and rejects
  anything that is not a host and a numeric port.
- Environment Checker results were compared with `Succeeded` while the module reports `SUCCESS`/`FAILURE`,
  so every check counted as failed.
- Arc category called the Arc validator without its mandatory parameters and needed Az modules that are not
  in the image; the menu wrote subscription/tenant ids to a temp script.
- `validationTimestamp` ended in `Z` but held local time.
- Menu text: Category 3 (not 4) is the AD port test; 6 categories (not 7); no vendor banner; one version.
- Static IP entry in the network bootstrap is validated (address, mask, gateway, DNS).

### Initial scaffold (2026-06-10)

- WinPE validation engine (`Start-AzlValidation.ps1`) with 6 validation categories
- `Build-WinPEImage.ps1` to assemble the bootable WinPE ISO
- Interactive menu (`Start-AzlBeacon.ps1`) and network bootstrap (`Start-NetworkBootstrap.ps1`)
- NIC drivers bundled from Dell SBE 5.0.2603.1641 (Broadcom, Intel E810/E823, Mellanox ConnectX)
